# melodrift

## Melodrift v21
- Interface version updated to v21.
- Android `versionCode` now increases with each GitHub Actions run, so new APKs can replace older installations.
- The v20 source already contains the Autorisations screen, multi-selection and floating-player components; this update preserves them.
- The obsolete `patch_melodrift.py` from v20 was removed because its search patterns do not match the included `www/index.html`.
